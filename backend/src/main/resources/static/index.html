Appeler l'API (PowerShell)

Toutes les routes sauf /api/auth/** et /api/status demandent le jeton JWT reçu à la connexion.

# 1. Se connecter (ou /api/auth/register avec fullName) : on garde le jeton
$auth = Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth/login -ContentType 'application/json' `
        -Body '{"email":"vous@exemple.tn","password":"votre-mot-de-passe"}'
$h = @{ Authorization = "Bearer $($auth.token)" }

# 2. Appeler les routes protégées
Invoke-RestMethod http://localhost:8080/api/parcels -Headers $h
Invoke-RestMethod "http://localhost:8080/api/parcels/1/irrigation?days=7" -Headers $h      # M2
Invoke-RestMethod "http://localhost:8080/api/ai/price?horizonWeeks=12" -Headers $h         # M4
